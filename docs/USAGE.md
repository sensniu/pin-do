# PinDo 使用指南

日常操作和数据回顾的详细说明。安装与数据存储见 [安装说明](../INSTALL.md)，同步配置见 [WebDAV 说明](WEBDAV.md)。

## 日常操作

- 菜单栏的单色“圆头图钉＋倾斜便利贴”图标随系统深浅色显示；点击菜单可打开白板、查看同步状态、手动同步、配置同步和退出。关闭白板后应用继续运行，再打开保留草稿及本次运行的布局。
- 第一次按 `⌘Q` 显示提示，2 秒内再按一次或按住约 1 秒才真正退出；短按松开取消本次长按，超时和切换应用取消确认。鼠标点退出菜单会显示确认。退出先保存本地草稿与备份，待发内容下次继续。
- 开机自启默认关闭。安装到“应用程序”后可从“设置 → 通用”按需开启；系统需要允许时显示等待状态。登录自启仅后台运行，不弹白板；普通手动启动打开白板。

- 点击 `+` 或 `⌘N` 新增，只填标题后按 `⌘↩` 即可保存。星数默认 1，DDL 和备注按需展开；修改后的取消和删除都有明确确认。
- 开启截止时间后可设置预计开始，默认“现在”，首次保存后固定；开始不能晚于截止，也可清除开始而只保留截止。过去的DDL不自动补造开始，旧事项同样保持未设置。清除截止后，保存时一起清除开始。
- 有安排的便利贴使用一行起止时间与细时间条，放不下时显示当前关键时间；悬停或展开查看完整安排。时间条表达计划窗口消耗，不代表完成百分比。到点只做一次轻微强调，系统减少动态效果时使用静态显示。
- 在具体项目白板新建时自动归属该项目；在全部或未分配白板中默认未分配。点击编辑器的项目标签可按需更改。
- 首次窗口约占当前屏幕可用桌面65%的面积，不最大化；小屏幕受最小可读尺寸限制。已有窗口继续记住手动大小和位置，显示器断开时修正到可见范围。
- 顶部工具栏与白板操作合并为一行，项目栏高约36点。未选中标签不保留对勾空位，选中后才加对勾。
- 顶部左侧固定“全部待办”和“未分配项目”，右侧是横向滚动的彩色项目标签；项目名完整显示，选中项有勾选和描边。
- 启动回到上次白板（失效项目回到全部），按当前紧急程度重新整理；本次运行内，每张白板独立保留位置和堆叠顺序，切换只刷新内容，不重排已有卡片。重新启动会覆盖手动位置。
- 拖便利贴可自由摆放、重叠，点击编辑或拖动会置顶；拖白板空白处平移。新增事项只寻找新卡片的合适空位，已有卡片不动；颜色按时间和 DDL 正常刷新。远端同步收到新增事项也遵循此规则。
- 白板右上角九宫格按钮及“显示 → 重新排列当前白板”仅整理当前白板，覆盖手动位置、解除堆叠并适配全局；旁边的圆形刷新箭头用于 WebDAV 同步。底部“适应”及 `⌘0` 只调整视野。
- 菜单“项目 → 管理项目…”支持新建、编辑名称和颜色、归档、恢复和删除。颜色编辑后按“保存”提交，取消保留原色。归档自动将未完成事项转入未分配；恢复不自动移回。同名项目通过独立 ID 区分。
- 删除项目时，选择将未完成事项转入未分配或放弃；已完成历史及原项目关联保留。
- 便利贴右上角勾选图标代表完成；全窗口只保留最近一次完成的 3 秒撤回控件，切换白板不重置倒计时。
- 点击便利贴展开编辑，可直接保存并完成；删除代表放弃并保留独立记录。缩小到 70% 以下时，完成图标也先展开，避免误触。双指缩放、滚动或拖动白板浏览，`⌘0` 适应白板。
- 便利贴宽度固定，高度按标题和备注自动调整；标题最多两行，备注最多三行，展开查看完整内容。文字变高或变短时保留卡片中心和邻居位置，允许重叠，当前缩放不变；可按 `⌘0` 查看完整范围。撤回完成恢复原位置，位置已被占用时也不挤动其他卡片。
- “PinDo → 设置… → 外观”（`⌘,`）可以选择渐变起点、终点和逾期固定色，支持颜色选择器、六位色值、预览与恢复默认。七天内逐渐接近终点色，超过七天使用起点色；逾期不再渐变。保存颜色不会重排卡片。
- 外观随 macOS 切换为中性浅色/石墨深色；无 DDL 为中性灰，默认临近 DDL 渐变紫，逾期为固定珊瑚色并排在外围。文字根据纸面自动选择黑色或白色，次要文字也保持清晰。仅全部待办的便利贴使用项目色边框，具体项目和未分配白板使用中性轮廓；编辑态同样遵循此规则。

项目和事项 ID 不需要用户配置。

概览中可展开查看完成/放弃事项，活动事项可回到白板编辑；当前没有自动下载更新或按时完成率。

## 概览与统一设置

- 顶部“白板 / 概览”切换，白板和概览保持挂载，切换保留缩放、手动摆放及阅读位置。首次概览沿用当前白板项目范围；概览内部为“现在 / 回顾”。
- “现在”只按项目筛选，展示待办总数、严格逾期、未来24小时内到期及今天完成。三个待办数字并非相加关系；进入24小时窗口、DDL到点和午夜会自动更新。
- “需要留意”最多预览5项：先逾期，再24小时内到期，再长期等待的3星事项；按清楚的时间/星级规则去重排序。查看全部不截断集合。项目、星级和等待时间分布合并到一块切换。
- “回顾”提供近7/30/90天和自定义，初始近30天；展示完成、新增及创建到完成的中位数。趋势/完成日历在同一区域切换，下方列出范围内最近5项完成成果；进一步的项目/跨度分布默认收起，本期放弃独立查看。
- 完成日历按当前时区逐日统计，周一开始；0、1、2–3、4–6、7+使用固定色档，点击日期的明细与完成总数对账。长于31天的趋势按周聚合，首尾周按所选日期计算；不使用新增/完成相除冒充完成率。
- 创建到完成为实际时间跨度，包含等待，不是实际工时。按24小时一天分桶，中位数保留有效样本量；异常不补0，无样本显示“—”。
- 点击数字、事项或图表打开同窗口明细：宽窗分栏、窄窗覆盖；Esc或关闭返回原位置。活动事项可“在白板中打开”，保存/取消后通过“返回概览”回到原条件；完成/放弃只读查看。
- 项目按稳定ID和当前保存归属统计；归属待确认不等于未分配。待确认入口按事项去重，跨项目归属问题单独说明。隐藏的历史范围不会阻断现在页；页面/图表切换复用内存快照，不新增文件或录入要求。
- “回顾 → 进一步看看 → 时间安排”展示计划开始至完成的平均跨度、中位数、平均计划窗口与按时完成样本数。使用完成时固定的一份安排，旧记录缺失字段不补0，早于预计开始就完成的事项独立查看；含等待，不代表工时。同步安排冲突须先确认后再完成。
- `⌘,` 或齿轮打开同一个设置面板：通用管理登录启动，外观管理紧急程度颜色，同步管理连接/暂停/错误/冲突，数据管理存储位置和备份。项目名称与颜色仍在“项目 → 管理项目…”。
- 同步控件提供可见下拉入口，不再必须右键才能找设置。状态栏保留打开应用、新建、同步、设置与退出。文字撤销和3秒完成撤回分开。
- 待办删除入口统一叫“放弃待办”；取消输入叫“舍弃修改”。项目删除先选择保留待办转未分配或放弃，默认保留，最后明确确认“删除项目”。设置/项目面板切换有未保存输入保护。
