# PinDo

Mac 原生便利贴白板待办软件。完整需求与后续规划维护在 [PROJECT_PLAN.md](PROJECT_PLAN.md)。

当前版本为 **v0.1.0**，使用 SwiftData 保存本地待办、完成与放弃记录、操作事件和编辑草稿，支持自动备份及手动导出恢复。保留已确认的紧凑便利贴布局。完整的安装、升级与数据保护说明见 [INSTALL.md](INSTALL.md)。

## 安装版本

打开 `build/releases/PinDo-0.1.0-arm64.dmg`，将 `PinDo.app` 拖到“应用程序”。正式版首次启动为空白白板，底部显示“本地保存 · v0.1.0”。

正式数据固定在 `~/Library/Application Support/PinDo/`，替换程序包不删除该目录。升级前建立一致性数据库快照，保留最多 3 份；自动逻辑备份保留最近 7 个有备份日期。菜单“数据”提供导出、恢复与打开数据目录。

## 运行

需要完整 Xcode 与 macOS 14 或以上，当前在 Apple silicon Mac 上开发。

1. 用 Xcode 打开 `PinDo.xcodeproj`。
2. 选择 `PinDo` scheme，运行目标选择 `My Mac`。
3. 按 `⌘R` 运行。

也可以从终端构建：

```sh
zsh scripts/build-app.sh
open build/DerivedData/Build/Products/Debug/PinDo.app
```

所有派生产物保存在项目的 `build/`，没有 Python 或 Conda 运行依赖。Debug 使用独立的 `~/Library/Application Support/PinDo-Development/`，Release 固定使用正式 `PinDo/` 数据目录，测试使用临时目录。不要通过切换构建配置共享正式数据库。

只有显式传入 `--demo` 启动参数时才使用不落盘的示例数据模式。

## 日常操作

- 点击右上角 `+` 或 `⌘N` 新增。
- 点击便利贴正文展开编辑；右上角归档图标表示完成。
- 完成后右上角有 3 秒撤回圆环，只恢复最近完成的一项。
- 编辑时可修改 1～3 颗星、截止日期和时间、备注与示例类别，也可删除（放弃）。
- 双指捏合或右下角按钮缩放，双指滚动或拖动白板浏览，`⌘0` 恢复适应白板。
- 默认随 macOS 外观切换；无 DDL 使用中性灰，有 DDL 随临近变紫，逾期暂用珊瑚色并排在外围。

紫色阈值、逾期颜色、示例类别与编辑提交方式均为原型方案，可继续调整。编辑与完成不重排；新增和重新启动时重排。

应用图标取自用户提供的 `asset/pin-do.png`，保持原设计，仅转换成 macOS 的多分辨率 ICNS。`scripts/generate-icon.sh` 可重新生成图标。

## 打包

```sh
zsh scripts/package-dmg.sh
```

脚本先执行测试，再构建 Release、添加本机临时签名并生成带校验的 DMG。安装镜像包含应用和安装说明；标准镜像另提供 Applications 快捷入口，受限环境使用 UDF 镜像时通过访达打开“应用程序”安装。不包含用户数据、示例数据文件、日志或构建缓存。打包暂存目录自动清理。

## 测试

Xcode 中按 `⌘U`，或执行：

```sh
zsh scripts/test.sh
```

测试目标直接编译相同的领域、规则、白板状态和存储源文件，无需启动应用或使用真实数据。覆盖时间边界、稳定排序、20/100/300 张卡片布局、位置保留、连续撤回，以及实际数据库写入、重开、回滚、升级快照、旧版本拒绝写入新数据、备份校验与恢复。

当前 20 项测试通过；升级验证实际重新打开快照中的数据库，确认事项 ID 和历史事件保留。Release 已独立启动并检查固定数据位置与备份菜单。300 张卡片目前仅验证布局计算与无重叠，尚未测量大量卡片实际渲染性能。

升级 Xcode/SDK 后也必须重新执行数据库测试。存储模型使用与生成模型一致的显式 backing/observation 结构，避免当前工具沙盒中的宏插件限制；未来改存储字段需保留旧版 Schema 并加入迁移，不得清空旧库重新开始。
