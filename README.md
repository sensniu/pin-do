# PinDo

把待办贴在白板上。

PinDo 是一款 macOS 原生便利贴待办应用。用白板摆放任务，用星级区分重要程度，用颜色感知紧急程度，让工作、学习和生活中的事项一目了然。

![PinDo 白板：不同项目、预计开始、时间条、临近截止、逾期及无截止时间的便利贴](asset/screenshots/whiteboard.jpg)

## 主要功能

- **轻重缓急，一眼可见**：1–3星标记重要程度，临近截止逐渐变色，逾期单独标色，无截止保持浅灰；配色可自定义。
- **安排什么时候做**：设置预计开始与截止，紧凑时间条显示计划时间的消耗，完整安排点击即可查看。
- **每个项目一张白板**：彩色标签快速切换，也能在“全部待办”查看总览，用项目色边框区分归属。
- **按自己的习惯摆放**：便利贴可拖动、堆叠，白板支持平移、缩放和一键重排；备注展开后查看全文。
- **完成后撕掉**：完成归档，3秒内可撤回最近一项并恢复原位置。
- **回顾自己的进展**：查看当前待办、完成趋势、完成日历和安排跨度，点击数字或图表查看具体事项。
- **融入 Mac 日常**：跟随系统浅深色，关闭窗口后可继续后台运行，支持状态栏入口和可选开机自启。

## 适用平台

当前版本适用于 **macOS 14 及以上的 Apple Silicon（M系列）Mac**，目前仅提供 Mac 版。

## 安装

1. 打开 `.dmg` 安装包，将 **PinDo.app 拖到“应用程序”**。
2. 安装完成后推出镜像，从“应用程序”启动 PinDo。

升级时先从菜单真正退出旧版，再拖入替换，原有数据会保留。更多说明见 [安装说明](INSTALL.md)。

## WebDAV 同步

支持通过自己的 WebDAV 服务在多台 Mac 之间同步待办和项目。本地优先、离线可用，提供自动备份与手动导出。

1. 打开 **PinDo → 设置… → 同步**，填写服务器地址、账号和应用授权密码。
2. 手动填写一个专用同步目录（如 `PinDo`），各设备使用相同的服务器、账号和目录，并升级至v1.1.0或以上。
3. 点击 **“连接并合并”**，通过兼容性检查后自动同步；也可点击白板工具栏的刷新按钮立即同步。

详细操作见 [使用指南](docs/USAGE.md)，连接配置见 [WebDAV 说明](docs/WEBDAV.md)。
