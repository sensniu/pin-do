# PinDo

把待办贴在白板上。

PinDo 是一款 macOS 便利贴待办软件。每件事都是白板上的一张便利贴，随着截止时间临近逐渐变色，让你一眼看到要做什么、哪些更紧急。适合管理个人工作、学习和生活中的事项。

## 主要功能

- **便利贴待办**：记录标题、备注和截止时间，用1–3颗星标记重要程度。
- **截止时间配色**：临近截止逐渐醒目，逾期单独标色，无截止时间保持浅灰；支持自定义颜色。
- **项目白板**：每个项目一张白板，也能在“全部待办”中查看所有事项。
- **自由摆放**：自由拖动、堆叠便利贴，缩放浏览白板，支持一键整理。
- **完成与回顾**：完成后归档，支持短时撤回，通过趋势图、完成日历等回顾进展。
- **融入 Mac**：跟随系统浅深色，支持状态栏常驻和可选开机自启。

## 适用平台

当前版本 **v1.0.0**，适用于 **macOS 14 及以上的 Apple Silicon（M系列）Mac**，目前仅提供 Mac 版。

## 安装

1. 打开 `.dmg` 安装包，将 **PinDo.app 拖到“应用程序”**。
2. 安装完成后推出镜像，从“应用程序”启动 PinDo。

升级时先从菜单真正退出旧版，再拖入替换，原有数据会保留。更多说明见 [安装说明](INSTALL.md)。

## WebDAV 同步

支持通过自己的 WebDAV 服务在多台 Mac 之间同步待办和项目，数据保存在本地，离线也能使用。

1. 打开 **PinDo → 设置… → 同步**，填写服务器地址、账号和应用授权密码。
2. 手动填写一个专用同步目录（如 `PinDo`），多台 Mac 使用相同的服务器、账号和目录。
3. 点击 **“连接并合并”**，通过兼容性检查后自动同步；也可点击白板工具栏的刷新按钮立即同步。

详细操作见 [使用指南](docs/USAGE.md)，连接配置见 [WebDAV 说明](docs/WEBDAV.md)。
